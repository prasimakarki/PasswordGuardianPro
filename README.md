# 🔒 Password Guardian Pro

**A Python-based password security analysis tool**

---

## 📌 About The Project

Password Guardian Pro is a comprehensive password security analysis tool built with Python. It helps users evaluate password strength, detect common patterns, check for data breaches using the Have I Been Pwned (HIBP) API, and generate secure passwords.

### Key Features:
- ✅ **Password Strength Analysis** (0-6 scoring system)
- ✅ **Entropy Calculation** (based on Shannon's formula)
- ✅ **Breach Database Check** (checks against 12+ billion leaked passwords)
- ✅ **Password History Tracking** (custom linked list data structure)
- ✅ **Secure Password Generator** (customizable length and character types)
- ✅ **Professional GUI** (Tkinter with three tabs)

---

## 🛠️ Technologies Used

- Python 3.14
- Tkinter (GUI)
- hashlib (SHA-1, SHA-256 hashing)
- urllib (HIBP API integration)
- threading (responsive GUI)
- unittest (testing)
